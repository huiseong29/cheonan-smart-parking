# 천안역 생활권 스마트 주차

천안역 생활권 스마트 주차 UX 프로토타입입니다. 배포와 유지보수를 위해 프론트엔드, 백엔드, 문서를 분리했습니다.

## 폴더 구조

- `frontend/`: React, Vite, Tailwind 기반 사용자 앱
- `backend/`: Express 기반 API 서버 골격
- `docs/`: 사업/기획/기능정의 Markdown 문서

## 실행

프론트엔드:

```bash
cd frontend
npm install
npm run dev
```

백엔드:

```bash
cd backend
npm install
npm run dev
```

루트에서 실행할 수도 있습니다.

```bash
npm run dev:frontend
npm run dev:backend
```
