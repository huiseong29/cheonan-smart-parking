# 천안역 생활권 스마트 주차 UX 기능정의서

## 1. 문서 개요

### 1.1 문서 목적

본 문서는 천안역 생활권 스마트 주차 서비스의 기본 기능, 사용자 흐름, 화면 구성, 버튼 동작, 데이터 연동, MVP 범위를 정의하기 위한 기능정의서이다.

서비스의 목적은 천안 공영주차장 이용 과정에서 발생하는 정보 단절, 결제 단절, 혜택 단절을 하나의 UX 흐름으로 연결하여 시민과 방문객이 주차 전부터 출차 후까지 끊김 없이 이용할 수 있도록 하는 것이다.

### 1.2 서비스명

가칭: 천안 스마트 주차 링크

### 1.3 대상 공간

- 1차 실증 공간: T-13 스마트 주차장
- 확장 대상: 천안시 공영주차장 54개소
- 주요 생활권: 천안역, 신부동, 병원, 시장, 축제 및 행사장 인근

### 1.4 핵심 컨셉

정보도, 결제도, 혜택도 끊기지 않는 주차장

사용자는 앱 첫 화면에서 주차 가능한 곳을 확인하고, 주차장 진입 후 가장 가까운 빈자리를 안내받으며, 주차 후에는 자동결제와 할인 혜택을 한 화면에서 처리한다. 결제 후에는 30분 이내 출차 유예 시간이 제공되고, 출차 후에는 이용내역과 결제내역을 확인할 수 있다.

## 2. 사용자 유형

| 사용자 유형 | 주요 니즈 | 핵심 기능 |
|---|---|---|
| 60~70대 어르신 | 정산기 조작 없이 쉽게 결제 | 하이패스형 자동결제, 큰 글자 UI, 단순 버튼 |
| KTX 이용 직장인 | 도착 전 주차 가능 여부 확인 | 실시간 지도, 최적 주차장 추천, KTX 도착 시간 연동 |
| 외부 여행객 | 지역 혜택을 쉽게 적용 | QR 여행지원 할인, 방문객 온보딩, 디지털 영수증 |
| 30~40대 천안 시민 | 정확한 빈자리 정보와 할인 적용 | 지역화폐 연동, 내 차 위치 저장, 요금 확인 |
| 관리자 | 주차장 현황과 장애 대응 | 주차 현황 대시보드, 센서 상태, 결제/할인 로그 |

## 3. 전체 서비스 흐름

### 3.1 기본 흐름

1. 앱 실행
2. 이용 전 지도 화면 진입
3. 주차장 또는 위치 검색
4. 지도에서 주차 가능한 곳 확인
5. 바텀시트에서 주차 가능 차량 수, 이용요금, 할인 정보 확인
6. 주차장 선택
7. 차량 번호 등록 또는 확인
8. 주차장 진입
9. 가장 가까운 주차 가능 자리 안내
10. 주차 위치 저장
11. 주차 세션 시작
12. 주차시간, 이용시간, 현재 요금, 할인 정보 확인
13. 할인 입력 또는 자동 할인 적용
14. 결제하기 또는 하이패스형 자동결제 등록
15. 결제 완료
16. 30분 이내 출차 타이머 표시
17. 출차 완료
18. 이용내역, 결제내역, 디지털 영수증 확인

### 3.2 화면 상태 구분

| 상태 | 설명 | 대표 화면 |
|---|---|---|
| 이용 전 | 주차장을 찾고 선택하는 단계 | 지도 화면, 검색, 바텀시트 |
| 이용 중 | 주차장에 진입해 자리를 찾고 주차하는 단계 | 층별 지도, 자리 안내, 내 차 저장 |
| 주차 후/출차 전 | 주차 세션이 진행 중이며 요금과 혜택을 확인하는 단계 | 내 차, 결제, 혜택 |
| 결제 후 | 결제가 완료되고 출차 유예 시간이 시작된 단계 | 결제 완료, 30분 타이머 |
| 출차 후 | 주차 이용이 종료된 단계 | 이용내역, 결제내역, 영수증 |

## 4. 정보 구조

### 4.1 하단 탭

하단 탭은 기본적으로 5개로 구성한다.

| 탭 | 역할 |
|---|---|
| 지도 | 앱 첫 화면. 주차 가능 장소 검색 및 선택 |
| 내 차 | 저장된 차량 위치와 주차 세션 확인 |
| 결제 | 현재 요금, 할인, 결제, 자동결제 등록 |
| 혜택 | 지역화폐, 감면, QR 여행지원 할인 적용 |
| 내 정보 | 차량 번호, 결제수단, 글자 크기, 이용내역 관리 |

### 4.2 앱 첫 화면 원칙

앱 첫 화면은 홈 요약 화면이 아니라 지도 기반 이용 전 화면이다.

첫 화면에는 다음 요소가 반드시 표시되어야 한다.

- 상단 주차장/위치 검색창
- 천안시 공영주차장 지도
- 주차 가능 여부를 나타내는 마커
- 마커 안 빈자리 수 또는 만차 상태
- 현재 위치 버튼
- 필터 칩
- 하단 바텀시트
- 하단 탭 바

## 5. 이용 전 기능 정의

### 5.1 지도 기반 주차장 탐색

| 항목 | 내용 |
|---|---|
| 기능명 | 지도 기반 주차장 탐색 |
| 대상 사용자 | 전체 사용자 |
| 목적 | 출발 전 주차 가능 여부를 직관적으로 확인 |
| 입력값 | 현재 위치, 검색어, 목적지, 필터 |
| 출력값 | 주차장 마커, 빈자리 수, 혼잡도, 바텀시트 목록 |
| 우선순위 | MVP 1순위 |

#### 화면 구성

- 화면 전체를 지도 영역으로 구성한다.
- 상단에는 주차장 또는 위치 검색창을 배치한다.
- 지도 위에는 주차장별 마커를 표시한다.
- 마커에는 현재 주차 가능한 차량 수를 숫자로 표시한다.
- 만차 상태는 숫자 대신 `만차`로 표시한다.
- 데이터 확인 중인 경우 `확인중`으로 표시한다.

#### 마커 상태

| 상태 | 색상 | 표시 |
|---|---|---|
| 여유 | 초록 | 빈자리 수 |
| 혼잡 | 노랑 | 빈자리 수 |
| 만차 | 빨강 | 만차 |
| 데이터 확인 중 | 회색 | 확인중 |

#### 버튼 및 동작

| 버튼/동작 | 결과 |
|---|---|
| 마커 탭 | 해당 주차장 카드가 바텀시트 상단에 표시 |
| 현재 위치 버튼 | 지도 중심을 현재 위치로 이동 |
| 주차장 카드 탭 | 주차장 상세 화면으로 이동 |
| 층별 현황 보기 | 이용 중 화면으로 이동 |
| 길안내 | 앱 내 경로 안내 또는 외부 지도 앱 연결 |

### 5.2 상단 검색

| 항목 | 내용 |
|---|---|
| 기능명 | 주차장/위치 검색 |
| 대상 사용자 | 전체 사용자 |
| 목적 | 목적지 주변 주차 가능 장소 검색 |
| 입력값 | 주차장명, 지명, 역, 병원, 시장, 행사장 |
| 출력값 | 검색 기준 주변 주차장 목록 |
| 우선순위 | MVP 1순위 |

#### 검색창 문구

`주차장 또는 위치를 검색하세요`

#### 검색 결과 반영

- 지도 중심이 검색 위치로 이동한다.
- 주변 주차장 마커가 갱신된다.
- 바텀시트 목록이 거리순 또는 추천순으로 갱신된다.
- 검색 결과가 없으면 가까운 공영주차장 안내를 제공한다.

### 5.3 바텀시트 주차장 카드

| 항목 | 내용 |
|---|---|
| 기능명 | 주차장 정보 바텀시트 |
| 대상 사용자 | 전체 사용자 |
| 목적 | 지도에서 선택한 주차장의 핵심 정보를 빠르게 확인 |
| 우선순위 | MVP 1순위 |

#### 바텀시트 상태

| 상태 | 설명 |
|---|---|
| 접힘 | 지도 중심, 간단 요약만 표시 |
| 중간 | 대표 주차장 카드 2~3개 표시 |
| 펼침 | 주차장 목록 전체 표시 |

#### 카드 필수 정보

- 주차장명
- 현재 주차 가능 차량 수
- 이용요금
- 예상 요금
- 할인 가능 정보
- 자동결제 가능 여부
- 목적지까지 거리
- 목적지까지 예상 이동 시간
- 층별 빈자리 미리보기

#### 카드 버튼

| 버튼 | 동작 |
|---|---|
| 층별 현황 보기 | 해당 주차장의 이용 중 화면으로 이동 |
| 길안내 | 주차장까지 경로 안내 |
| 하이패스 가능 | 자동결제 등록 화면으로 이동 또는 상태 안내 |
| 할인 보기 | 해당 주차장에서 가능한 할인 목록 표시 |

### 5.4 최적 주차장 추천

| 항목 | 내용 |
|---|---|
| 기능명 | 최적 주차장 추천 |
| 대상 사용자 | KTX 이용자, 방문객, 일상 이용자 |
| 목적 | 가장 빨리 주차할 수 있는 주차장 추천 |
| 우선순위 | MVP 이후 고도화 |

#### 추천 기준

추천 기준은 단순 거리순이 아니라 주차 성공 가능성과 총 소요 시간을 기준으로 한다.

1. 현재 빈자리 수
2. 빈자리 데이터 신뢰도
3. 목적지까지 총 이동 시간
4. 주차장 회전율
5. 출차 혼잡도
6. 자동결제 가능 여부
7. 할인 적용 가능 여부

#### 추천 문구 예시

`가장 빨리 주차할 수 있어요`

`신부5공영주차장 · 빈자리 12면 · 도보 4분`

## 6. 이용 중 기능 정의

### 6.1 차량 번호 등록

| 항목 | 내용 |
|---|---|
| 기능명 | 차량 번호 등록 |
| 대상 사용자 | 전체 사용자 |
| 목적 | 번호판 인식, 자동결제, 주차 위치 저장의 기준 정보 확보 |
| 입력값 | 차량 번호 |
| 출력값 | 등록된 차량 정보 |
| 우선순위 | MVP 1순위 |

#### 진입 시점

- 앱 최초 이용 시
- 주차장 선택 후 차량 번호가 없는 경우
- 하이패스형 자동결제 등록 시

#### 화면 문구

`차량 번호를 등록해주세요`

입력 예시: `12가 3456`

#### 버튼

| 버튼 | 동작 |
|---|---|
| 등록하기 | 차량 번호 저장 후 다음 화면 이동 |
| 나중에 하기 | 지도 화면으로 이동하되 자동결제 전 재요청 |

### 6.2 층별 실내 지도

| 항목 | 내용 |
|---|---|
| 기능명 | 층별 실내 지도 |
| 대상 사용자 | 전체 사용자 |
| 목적 | 주차장 내부에서 빈자리를 빠르게 찾도록 안내 |
| 입력값 | 주차장 ID, 층, 주차면 상태 |
| 출력값 | 층별 평면도, 빈자리, 추천 자리 |
| 우선순위 | MVP 1순위 |

#### 화면 구성

- 상단 주차장명
- 현재 주차 가능 차량 수
- 층별 탭
- 2D 또는 3D 실내 지도
- 빈자리 표시
- 추천 자리 표시
- 하단 주요 버튼

#### 층별 탭 예시

- `B1 3`
- `1F 5`
- `2F 만차`
- `3F 12`

#### 주차면 상태

| 상태 | 표시 |
|---|---|
| 빈자리 | 초록 |
| 사용 중 | 회색 |
| 추천 자리 | 초록 테두리 강조 |
| 선택한 자리 | 진한 강조 |
| 장애인 전용 | 파랑 |
| 전기차 충전 | 보라 |

### 6.3 가장 가까운 주차자리 안내

| 항목 | 내용 |
|---|---|
| 기능명 | 가장 가까운 주차자리 안내 |
| 대상 사용자 | 전체 사용자 |
| 목적 | 주차장 진입 후 배회 시간을 줄임 |
| 입력값 | 차량 진입 위치, 빈자리 상태, 목적 동선 |
| 출력값 | 추천 층, 추천 구역, 추천 주차면 |
| 우선순위 | MVP 1순위 |

#### 안내 기준

- 진입구에서 가까운 위치
- 현재 비어 있는 자리
- 이동 동선이 단순한 자리
- 장애인, 전기차, 경차 등 조건에 맞는 자리

#### 화면 문구 예시

`3층 B구역에 가장 가까운 빈자리가 있습니다`

`오른쪽 통로로 이동하세요`

#### 버튼

| 버튼 | 동작 |
|---|---|
| 가까운 자리 안내 | 추천 자리와 이동 방향 표시 |
| 다른 자리 보기 | 같은 층 또는 다른 층의 빈자리 표시 |
| 이 자리로 이동 | 선택한 자리 안내 시작 |

### 6.4 주차 위치 저장

| 항목 | 내용 |
|---|---|
| 기능명 | 내 차 위치 저장 |
| 대상 사용자 | 전체 사용자 |
| 목적 | 사용자가 주차 후 차량 위치를 쉽게 찾도록 저장 |
| 입력값 | 주차장, 층, 구역, 주차면 번호, 입차 시간 |
| 출력값 | 저장된 차량 위치, 주차 세션 |
| 우선순위 | MVP 1순위 |

#### 저장 흐름

1. 사용자가 빈자리를 탭한다.
2. 확인 팝업이 표시된다.
3. 사용자가 저장하기를 누른다.
4. 저장 완료 화면이 표시된다.
5. 주차 세션이 시작된다.

#### 확인 팝업 문구

`3층 B-12 자리에 주차하셨나요?`

#### 버튼

| 버튼 | 동작 |
|---|---|
| 저장하기 | 위치 저장, 주차 세션 시작 |
| 다시 선택 | 팝업 닫기, 자리 재선택 |

#### 저장 완료 화면

표시 정보:

- 주차 위치

## 14. 비기능 요구사항

### 14.1 접근성

- 글자 크기 설정을 제공한다.
- 주요 버튼은 충분한 터치 영역을 가진다.
- 색상만으로 상태를 구분하지 않는다.
- 초록/노랑/빨강 색상에는 반드시 `여유`, `혼잡`, `만차` 텍스트를 함께 제공한다.
- 주요 행동 버튼은 한 화면에 하나를 우선 강조한다.
- 고령자가 이해하기 쉬운 짧은 문장을 사용한다.

### 14.2 실시간성

- 빈자리 정보는 가능한 짧은 주기로 갱신한다.
- 데이터 지연 또는 센서 오류 시 `확인중` 상태를 표시한다.
- 앱 표시 정보와 현장 상태가 불일치할 경우 대체 주차장을 추천한다.

### 14.3 보안 및 개인정보

- 차량 번호, 결제수단, 위치 정보는 암호화 저장한다.
- 결제 정보는 PG 보안 기준을 따른다.
- 위치 정보 사용 목적을 명확히 고지한다.
- 사용자가 차량 번호, 결제수단, 이용내역 삭제를 요청할 수 있어야 한다.

### 14.4 장애 대응

- 센서 오류 시 해당 구역을 `확인중`으로 표시한다.
- 결제 실패 시 재결제, 결제수단 변경, 현장 호출을 제공한다.
- QR 인식 실패 시 코드 직접 입력을 제공한다.
- 네트워크 오류 시 마지막 갱신 시간을 표시한다.

## 15. 버튼 UX 가이드라인

### 15.1 버튼 문구 원칙

버튼은 사용자가 누른 뒤 어떤 일이 일어나는지 명확히 말해야 한다.

좋은 버튼:

- 층별 현황 보기
- 이곳으로 가기
- 가까운 자리 안내
- 주차 위치 저장
- 요금 확인하기
- 할인 입력하기
- 결제하기
- 하이패스형 자동결제 등록
- 출구 안내
- 이용내역 보기

피해야 할 버튼:

- 확인
- 다음
- 처리
- 계속

단, 팝업처럼 맥락이 명확한 경우에는 `확인`을 사용할 수 있다.

### 15.2 버튼 동작 원칙

| 주차 위치 저장 | 저장 완료 화면 |
| 결제하기 | 결제 완료 및 30분 타이머 |
| 할인 입력하기 | 할인 선택 또는 QR 스캔 화면 |
| QR 할인받기 | QR 스캔 화면 |
| 출구 안내 | 출구 방향 안내 |
| 이용내역 보기 | 이용내역 상세 |

## 17. 최종 시연 흐름

1. 앱을 실행하면 지도 화면이 첫 화면으로 열린다.
2. 지도에서 주차 가능한 곳이 숫자 마커로 표시된다.
3. 상단 검색창에서 목적지 또는 주차장을 검색한다.
4. 바텀시트를 올려 주차 가능 차량 수, 이용요금, 할인 정보를 확인한다.
5. 주차장을 선택한다.
6. 차량 번호를 등록한다.
7. 주차장 진입 후 가장 가까운 주차 가능 자리를 안내받는다.
8. 빈자리를 선택하고 주차 위치를 저장한다.
9. 주차 세션이 시작된다.
10. 내 차 또는 결제 화면에서 주차시간, 이용시간, 현재까지 이용요금, 할인 정보를 확인한다.
11. 할인 입력하기로 QR 또는 지역화폐 할인을 적용한다.
12. 결제하기 또는 하이패스형 자동결제를 이용한다.
13. 결제 완료 후 30분 이내 출차 타이머가 표시된다.
14. 출차 후 이용내역, 결제내역, 디지털 영수증을 확인한다.

## 19. 한 문장 정의

천안 스마트 주차 링크는 사용자가 지도에서 주차장을 찾고, 주차장 안에서 가까운 자리를 안내받고, 주차 후 요금과 혜택을 확인한 뒤, 정산기 없이 결제하고 30분 안에 출차할 수 있게 만드는 포용형 스마트 주차 UX 서비스이다.
